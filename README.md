**Netflix Churn Prediction**



**Project Overview**



This project focuses on predicting customer churn in Netflix using supervised machine learning techniques. The objective is to identify whether a customer is likely to churn based on user behavior, subscription details, and engagement patterns.



**Dataset Information**



Dataset Name: Netflix User Behavior Dataset



Source: Kaggle



Target Variable: churned



Task Type: Classification



**Research Questions**



RQ1: How effectively can baseline machine learning models predict customer churn?



RQ2: Which machine learning model performs best for churn prediction?



RQ3: How does preprocessing affect prediction performance?



RQ4: Which features contribute most to churn prediction?



RQ5: How sensitive are model rankings to evaluation metrics?



RQ7: Which model provides the best final recommendation for deployment?



**Machine Learning Models Used**



Logistic Regression

Decision Tree

K-Nearest Neighbors (KNN)

Random Forest



**Evaluation Metrics**
